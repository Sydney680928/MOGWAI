# MOGWAI - A modern RPN (Reverse Polish Notation) scripting language for industrial IoT automation and embedded systems. 

## Introduction

**MOGWAI** is a scripting engine for .NET, heavily inspired by the [**FORTH**](https://en.wikipedia.org/wiki/Forth_(programming_language)) and [**RPL**](https://en.wikipedia.org/wiki/RPL_(programming_language)) languages.  
It allows you to “power” your applications (for exemple as Excel and Word with VBA).

Developed in [.NET Standard](https://learn.microsoft.com/en-us/dotnet/standard/net-standard), **MOGWAI** can be integrated into .NET applications such as WinForms, WPF, MAUI, Console, Blazor, ASP, and more.

[The MOGWAI website](https://www.mogwai.eu.com) gathers all related links. 

## Documentation

## Examples

[Example applications](https://github.com/Sydney680928/MOGWAI_EXEMPLES) are available, with all their code, to learn how to integrate **MOGWAI** into your own applications.

## MOGWAI CLI

[MOGWAI CLI](https://github.com/Sydney680928/MOGWAI_CLI) is a console application that lets you use the MOGWAI language interactively.  
Each line you type is executed immediately, and all language commands and functions are available.

![MOGWAI CLI](./images/img02.png)

## MOGWAI STUDIO

[MOGWAI STUDIO](https://github.com/Sydney680928/MOGWAI_STUDIO) is a development IDE dedicated to the **MOGWAI** runtime.  
It allows you to connect to an application using the runtime and perform all necessary operations during development.

![MOGWAI STUDIO](./images/img04.png)

With **MOGWAI STUDIO**, development and debugging become much easier.

## Usage examples

The **MOGWAI** runtime has already been used in several industrial and testing applications involving serial and Bluetooth Low Energy communication.  
The most recent example (October 2025) is an electronic device test bench (developed in C# / .NET 8 for Windows) that uses **MOGWAI** to script tests for various products.
